# Proyecto2_EAFIT
Aplicación web para la gestión integral de almuerzos corporativos, que automatiza el registro de consumo mediante códigos QR, el control de pagos y saldos, y la visualización de métricas administrativas, apoyando la toma de decisiones a través de analítica básica y estimación de demanda.


## Instrucciones de uso

### Requerimientos minimos:
- Docker
- Python
- Django

### Recomendaciones:
- Tener un ambiente virtual de python

### Instrucciones
1. abrir un cmd en la carpeta del proyecto
2. ejecutar docker compose build
3. ejecutar docker compose up
4. buscar el contenedor proyecto en docker desktop
5. el la parte web, debajo de proyecto web dar click al numero que aparece(en la fecha que se escribe esto es el puerto 8000)
